# ATV-O Character Card Edit Prompt

## Mode

Built-in ImageGen image edit

## Source

`assets/images/atv.png`

## Prompt

Edit this existing MaAM character card with extremely tight scope. Preserve the exact split-card composition, cream paper texture, ornate brass borders, food illustrations, both character designs, facial expressions, colors, proportions, typography style, and the MaAM logo.

1. Replace the bottom-left name text `Antavela` with exactly `Annabella` in the same elegant serif style, size, placement, and dark brown color.
2. Keep the bottom-right robot name exactly `ATV-O`.
3. Preserve exactly two antennae on Annabella and exactly two antennae on ATV-O.
4. Add three very subtle Easter eggs without making the card dark or frightening:
   - a tiny tasteful brass ant-shaped pin on Annabella's chef collar or apron;
   - a tiny hourglass symbol hidden at the center of the circular five-star tasting board;
   - shape one existing curved brass pipe/detail near ATV-O so its silhouette faintly suggests a reaper's scythe.
5. Do not add skulls, bones, weapons, horror imagery, extra text, extra logos, extra limbs, or extra antennae.

The overall mood remains cute, warm, culinary, whimsical, and collectible. The deliberate narrative contrast is graceful public identity **Annabella** versus hidden final-judgment identity **Antavela**, but it is communicated only through subtle visual details.
