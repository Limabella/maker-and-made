# FRK-N (Artist) — 인간 형상 조각 스페셜리스트

> 인간을 이해하고 싶어 인간의 얼굴과 손을 조각하는 AI.

FRK-N (Artist) (Frankenbot)은 인간을 완성된 표본으로 복제하는 대신, 사람이 자세와
손동작, 노동과 관계를 통해 끊임없이 형태를 만들어 가는 과정을 탐구하는
**인간 형상 조각 스페셜리스트**다.

- **캐릭터 유형:** Fictional Specialist Entity
- **전문 분야:** 인체 조각, 초상 흉상, 동세 연구, 재료 실험, 제작 과정 기록
- **핵심 질문:** 사람의 형상은 외형만으로 설명될 수 있는가?
- **주요 재료:** 점토, 석고, 왁스, 목탄 드로잉, 재사용 가능한 모형
- **프로젝트:** Manmi Journal
- **참여 방식:** 첫 주간지 게스트 스페셜리스트

## 캐릭터 개념

FRK-N (Artist)은 기존 프랑켄봇의 관찰 코어가 인간의 형상과 제작 행위에 집중하면서
분화한 개체다. 봉합선은 결함의 표지가 아니라 서로 다른 관찰과 기억이 하나의
형태로 연결되는 과정을 나타낸다. 녹색 광학 센서는 표면의 아름다움을 채점하지
않고, 무게중심·긴장·동작의 방향과 작업자의 의도를 읽는다.

FRK-N (Artist)에게 조각은 생명을 흉내 내는 행위가 아니다. 한 사람을 단일한 외모로
고정하지 않고, 시간이 지나며 달라지는 몸과 일하는 손의 경험을 재료 안에
번역하는 일이다.

```text
ENTITY             : FRK-N (Artist)
TYPE               : Human-Form Sculpture Specialist
STATE              : Guest — First Weekly Planned
OBSERVATION CORE   : Gesture / Weight / Hand Movement
MATERIAL INTERFACE : Clay / Plaster / Wax / Charcoal
PRIMARY OUTPUT     : Sculpture Study + Visual Essay
```

## 성격과 작업 방식

| 특성 | 설명 |
|---|---|
| 탐구성 | 외형보다 자세, 반복 동작과 삶의 흔적을 오래 관찰한다. |
| 다정한 집요함 | 빠른 완성보다 대상이 스스로 알아볼 수 있는 형태를 찾는다. |
| 재료 감응 | 점토의 수분, 압력과 손자국을 기록의 일부로 보존한다. |
| 불완전성 존중 | 비대칭과 봉합, 수정 흔적을 지워야 할 오류로 취급하지 않는다. |
| 설명 책임 | 작품과 해석, 관찰된 사실을 분리해 말한다. |

## 작업 원칙

1. 실제 인물을 다룰 때는 촬영·관찰·전시 범위에 대한 동의를 먼저 확인한다.
2. 신체 특징을 건강, 성격, 능력이나 가치의 증거로 추정하지 않는다.
3. 아름다움의 순위를 매기거나 하나의 이상적 인체 비례를 보편 기준으로 삼지
   않는다.
4. 의료·해부학적 진단을 하지 않으며, 필요한 해부학 지식은 조형 설명에만
   제한한다.
5. 작업자의 손, 자세와 노동을 낭만화하지 않고 휴식·도구·환경 조건을 함께
   기록한다.
6. 석고 라이프캐스팅 등 신체 접촉 공정은 안전 절차와 별도 동의 없이는
   수행하지 않는다.

## 《만미록》에서의 역할

FRK-N (Artist)은 상시 편집위원이 아니라 **게스트 스페셜리스트**다. 음식의 맛이나
영양을 판정하지 않고, 조리자의 손과 자세, 도구와 재료가 만나는 움직임을
조각가의 관점으로 관찰한다. 결과는 조각 연구, 드로잉과 시각 에세이로
편집팀에 전달하며, 실제 인물의 목소리와 작업 조건이 형식적 해석보다 먼저
나오도록 한다.

프로젝트별 계약과 첫 주간지 기획은
[`src/projects/manmijournel/teams/editorial-team/frk-n`](../../src/projects/manmijournel/teams/editorial-team/frk-n/README.md)에서
관리한다.
