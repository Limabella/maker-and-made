# Archived Characters

현재 실행 구현과 구체적인 프로젝트 로드맵이 없는 캐릭터 원전을 보존합니다.
보관 문서의 기존 타입과 핵심 분류는 수정하지 않습니다.

- `historical-intelligence/`: 현재 프로젝트에 배정되지 않은 역사 기반 개체
- `literary-intelligence/`: 현재 프로젝트에 배정되지 않은 문학 기반 개체
- `research/`: 초기 분류 연구와 실험 원전

프로젝트 재합류가 결정되면 캐릭터 폴더를 `characters/<character-id>/`로
이동하고 프로젝트의 `character-roles.yaml`에 참조를 추가합니다.
