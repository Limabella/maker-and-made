- **운영 분류:** Record Entity
- **상태:** planned
- **프로젝트:** Manmi Journal
- **역할:** Taste Slip, 취재 기록, 검증 메모, 발행본과 정정 이력을 연결하는 기록 편찬자

- [ ] 검색 가능한 장기 아카이브 구현
