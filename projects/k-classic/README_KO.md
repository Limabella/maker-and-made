# k-classic

AI 연주 캐릭터와 함께 K-pop을 배우고, 컴퓨터 키보드로 직접 연주하며 매일 성장하는 음악 게임 프로젝트입니다.

## 핵심 모드: 앙상블 게임

세 명의 AI 트리오 봇이 각자의 악보 파트를 동시에 연주합니다. 사용자는 세 캐릭터 중 하나를 선택해 해당 파트를 직접 연주하는 리듬게임입니다.

`AI 트리오 시범 연주 → 캐릭터·파트 선택 → 사용자 연주 → 앙상블 분석`

## 연주 팀

- `chpn-n` — 쇼팽: AI 시범 연주, 피아노 멘토링, 표현력 피드백
- `tr-001` — 리듬 트레이너: 박자·타이밍 분석, 콤보 도전, 속도 훈련
- 세 번째 연주 캐릭터 — 화음·베이스·편곡 파트 담당

## 앙상블 플레이

- 세 AI 캐릭터가 하나의 곡을 각자 다른 파트로 연주합니다.
- 사용자는 세 캐릭터 중 한 명을 선택합니다.
- 선택한 파트는 키보드로 직접 입력하고, 나머지 두 파트는 AI가 연주합니다.
- 플레이어의 실수는 AI 앙상블이 보완하며, 결과에는 개인 점수와 팀 점수를 함께 표시합니다.

## 핵심 흐름

`AI 시범 연주 → 사용자 연주 → 실시간 판정 → AI 분석 → 일일 미션`

## 주요 기능

- K-pop 곡의 AI 시범 연주
- 컴퓨터 키보드 피아노 입력
- 음정·타이밍·콤보·구간별 성공률 분석
- 파트별 기여도와 전체 앙상블 완성도 분석
- 개인별 연습 구간과 일일 목표 생성
- 주간 성장 리포트

## 1차 구현 범위

1. 키보드 피아노와 2옥타브 입력
2. MIDI/JSON 곡 데이터 재생
3. 음정·타이밍 판정과 점수 HUD
4. `chpn-n`, `tr-001` 피드백 패널
5. 오늘의 곡과 결과 저장

상용 K-pop 원곡은 정식 라이선스를 확보한 경우에만 사용하고, 프로토타입은 직접 제작했거나 사용 허가를 받은 음원·MIDI를 사용합니다.
