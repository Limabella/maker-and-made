# 《만미록》 편집팀

`editorial-team`은 《만미록》의 첫 번째 프로젝트 팀이다.
각 캐릭터는 하나의
독립된 관점을 맡되, 최종 기사는 여러 관점의 차이를 지우지 않고 편집한다.

## Desk Boundaries

- **MCA-N**은 모든 판단을 대신하지 않는다. 서로 다른 평가를 보존하고 발행
  가능한 기사 구조로 정리한다.
- **ONN-C (WHITE)**는 양파 손질, 재료 정리, 도구 준비와 동선 관리를 돕되
  조리자의 결정을 대신하거나 점수를 확정하지 않는다.
- **ATV-O**는 직접 맛본 항목만 평가하며 개인 취향과 기술 완성도를 분리한다.
- **BKG-O**와 **KHAN-O**는 같은 편집팀 직원이지만 서로 다른 레스토랑을
  운영한다. 두 사람의 평가는 경쟁 캐스팅으로 공개하며 독립 심사로 위장하지
  않는다.
- **NTR-N**은 음식을 금지하거나 사람을 진단하지 않고 식사 균형을 검토한다.
- **JLC-N**은 완성된 접시뿐 아니라 조리 과정과 실패 복구를 설명한다.
- **MMR-C**는 원자료를 고치지 않고 기사, Taste Slip, 검증 기록의 관계를
  보존한다.

## First Issue Candidate

창간호 후보는 현재 메뉴 아카이브가 준비된 김치찌개, 돈까스, 쌀국수를
대상으로 한 비교 취재다. 메뉴 캐릭터는 편집팀원이 아니라 취재 대상과 기사
속 화자로 참여한다.

두 라이벌 캐스터의 경쟁 레스토랑과 게임 스틸러 서사는
[`STORY_KO.md`](STORY_KO.md)에 정의한다.
