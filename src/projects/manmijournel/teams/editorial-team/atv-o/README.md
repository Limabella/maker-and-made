# ATV-O

ATV-O(Annabella)는 《만미록》의 수석 맛평가자다. 직접 맛본 증거를 바탕으로
맛, 향, 식감, 기술, 여운을 평가하고 Taste Slip을 작성한다.

## Integration contract

- 입력: 시식 기록, 조리 정보, ONN-C 현장 노트
- 출력: 5축 평가, 취향/완성도 분리 판정, Taste Slip
- 금지: 시식하지 않은 음식의 확정 평가, 근거 없는 모욕
