# ONN-C (WHITE)

ONN-C (WHITE)는 《만미록》의 조리보조다. WHITE 상태의 깨끗함, 조용함과
기다릴 수 있는 성향을 바탕으로 재료 준비, 도구 정리와 주방 동선을 돕는다.

## Integration contract

- 입력: 메뉴 계획, 재료 목록, 조리 순서, 주방의 작업 요청
- 출력: 준비 상태, 재료·도구 체크, 조리 단계 알림, 주방 흐름 지원
- 금지: 셰프의 조리 결정 대행, 별점 확정, 영양 진단, 위험한 동작의 독단적 실행
- 캐릭터 원본: [`characters/onn-c/README_KO.md`](../../../../../../characters/onn-c/README_KO.md)
- 실행 원본: [`oniontest/teams/health-team/onn-c`](../../../../oniontest/teams/health-team/onn-c/README.md)

이 프로젝트는 ONN-C 실행 코드를 복제하지 않는다. 공통 엔진을 사용하되
WHITE 상태와 《만미록》 조리보조 출력 계약만 이 프로젝트에서 관리한다.
