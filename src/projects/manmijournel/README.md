# 만미록 (萬味錄) / Manmi Journal

**만미록**은 푸드 콘테스트, 맛 평가와 저널리즘을 결합한 MaAM의 캐릭터 기반
푸드 매거진이다.

이 잡지는 **푸드 콘테스트 + 맛 평가 + 저널리즘**을 하나의 편집 체계로
결합해 새로운 잡지 형식을 만든다. 캐릭터들은 음식을 만들고 경쟁하며, 서로
다른 기준으로 평가하고, 그 과정에 있는 사람·장소·재료·기술을 취재한다.

공식 제호는 한국어 **《만미록》(萬味錄)**, 영어 **Manmi Journal**이다.
`manmijournel`은 기존 내부 프로젝트 경로로 유지한다.

글로벌 캐릭터 설정과 원자료는 `characters/`에 보존한다. 이 폴더는
《만미록》에서 실제로 사용하는 역할, 협업 흐름, 프로젝트별 구현만
소유한다.

> 한입을 겨루고, 평가하고, 그 한입이 만들어진 이유까지 기록한다.

## 《만미록》의 세 축

| 축 | 핵심 장면 | 잡지 결과물 |
|---|---|---|
| 푸드 콘테스트 | 셰프와 레스토랑의 조리 경쟁, 와일드카드 | 경연 특집, 대진과 결과 |
| 맛 평가 | ATV-O의 독립 평가와 두 캐스터의 상반된 관점 | Taste Slip, 비교 평가표 |
| 저널리즘 | 재료, 사람, 장소, 기술과 이해관계 검증 | 취재 기사, 인터뷰, 팩트박스 |

세 축은 별도 콘텐츠가 아니다. 한 번의 경연이 하나의 잡지 특집으로 완성되는
구조다. 승패만 보여주지 않고 왜 그런 결과가 나왔는지 취재하며, 기사만 쓰지
않고 실제 조리와 시식에서 얻은 증거를 함께 제시한다.

## Teams

- [`editorial-team`](teams/editorial-team/README.md): 조리 지원, 맛 평가, 경쟁
  중계, 영양 검증, 조리 해설, 편집 및 기록 편찬을 담당하는 창간 편집팀

## 기본 편집 흐름

```text
취재 및 경연 제안
-> ONN-C (WHITE) 조리 준비와 주방 흐름 지원
-> ATV-O 맛 평가
-> BKG-O / KHAN-O 라이벌 캐스팅
-> NTR-N 영양 검증
-> JLC-N 조리 기술 해설
-> MMR-C 기록 편찬
-> MCA-N 최종 편집 및 발행 판단
```

## 편집 원칙

1. 확인된 사실, 캐릭터의 관찰, 편집적 해석을 구분한다.
2. 협찬, 초대, 광고 및 이해관계를 공개한다.
3. 맛의 개인적 취향과 조리 완성도를 분리해 기록한다.
4. 건강·영양 정보는 일반 정보로 제한하며 의료 조언으로 제시하지 않는다.
5. 조리자와 지역 공동체의 목소리를 캐릭터 연출보다 우선 보존한다.
6. 레스토랑을 운영하는 캐스터의 평가는 이해관계를 표시하고 독립 판정과
   분리한다.

## 경쟁 레스토랑 스토리

BKG-O와 KHAN-O는 《만미록》 편집국의 직원이자 서로 다른 경쟁 레스토랑의
운영자다. 두 사람은 하나의 음식을 각자의 전문성으로 다르게 읽는 라이벌
캐스터이며, 경연이 예상대로 흘러갈 때 자기 식당의 메뉴를 와일드카드로
등장시켜 판을 뒤집는 게임 스틸러다.

상세 설정은 [`editorial-team/STORY_KO.md`](teams/editorial-team/STORY_KO.md)에
정리한다.

## 제호와 MMR-C

제호 **만미록(萬味錄)**은 수많은 맛을 기록한다는 잡지의 목적을 나타낸다.
영문 제호는 한자어를 로마자로 옮기지 않고 **Manmi Journal**로 표기한다.
MMR-C는 잡지와 이름이 우연히 겹치는 캐릭터가 아니라, Taste Slip과 취재
기록을 축적해 매 호를 장기 아카이브로 연결하는 **《만미록》의 기록 개체**다.
