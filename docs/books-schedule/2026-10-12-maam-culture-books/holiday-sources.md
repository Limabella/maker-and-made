# 대한민국 공휴일 표시 · 2026년 10–12월

확인 기준: 2026-10-18. 우주항공청 「2026년 월력요항」과 한국천문연구원 달력자료를 참고했습니다.

| 날짜 | 요일 | 공휴일 |
|---|---|---|
| 2026-10-03 | 토요일 | 개천절 |
| 2026-10-05 | 월요일 | 개천절 대체공휴일 |
| 2026-10-09 | 금요일 | 한글날 |
| 2026-12-25 | 금요일 | 성탄절(기독탄신일) |

11월은 일요일 외 별도의 공휴일이 없습니다. 일요일 날짜는 기존처럼 빨간색, 일반 토요일은 파란색으로 유지합니다. 토요일과 겹치는 개천절은 공휴일 빨간색이 우선합니다. 크리스마스이브나 민간 기념일은 빨간날로 표시하지 않습니다.

공휴일 숫자와 이름을 빨간색으로 표시하고 해당 칸에 매우 옅은 붉은 배경을 적용했습니다. 기존 일정은 그대로 보존하고 파란색 체육 행사와 구분했습니다. 공휴일은 별도의 메타데이터 배열로 관리하므로 행사 건수를 부풀리지 않습니다.
