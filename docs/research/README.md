# Research Workspace

| Area | Purpose |
|---|---|
| [`journal/`](journal/) | 날짜별 연구 일지와 진행 기록 |
| [`ideas/`](ideas/) | 검증 전 아이디어 노트와 초기 제안 |
| [`experiments/`](experiments/) | 실행 가능한 실험, 벤치마크, 실험별 로그 |
| [`projects/`](projects/) | 프로젝트별 연구 개요와 통합 설계 |
| [`references/`](references/) | 공통 참고자료와 근거 목록 |

아이디어가 실제 검증 단계에 들어가면 `ideas/`에서 관련 실험 폴더로 연결하고,
날짜별 수행 결과는 `journal/` 또는 실험 내부 `logs/`에 기록합니다.
