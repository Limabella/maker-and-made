# MND-N 문맥 신호 라벨 정의 v1.0

이 라벨은 사용자의 실제 심리 상태나 성격을 진단하지 않는다. 제공된 발화에 **표현된 신호**만 분류한다. 근거가 부족하면 추측하지 않고 `uncertain`을 사용한다.

## Emotion

여러 감정이 함께 표현되면 복수 선택한다.

| Label | 정의 |
|---|---|
| `joy` | 기쁨, 만족 또는 긍정적 흥분이 명시됨 |
| `sadness` | 슬픔, 상실감 또는 낙담이 명시됨 |
| `anger` | 분노, 짜증 또는 적개심이 명시됨 |
| `fear` | 구체적 위협이나 위험에 대한 두려움이 명시됨 |
| `anxiety` | 미래의 불확실성에 대한 걱정이나 긴장이 명시됨 |
| `relief` | 부담이나 긴장이 줄었다는 표현이 명시됨 |
| `neutral` | 감정 표현 없이 사실이나 일반 요청만 있음 |
| `uncertain` | 문장만으로 감정을 판단할 근거가 부족함 |

`neutral`과 `uncertain`은 다른 감정 라벨과 함께 사용하지 않는다.

## Speech Act

한 발화의 주된 기능 하나를 선택한다.

| Label | 정의 |
|---|---|
| `gratitude` | 고마움을 표현함 |
| `apology` | 유감이나 책임을 인정하지만 관계 재개 요청은 없음 |
| `rejection` | 제안, 요청 또는 행동을 거절함 |
| `help_request` | 도움이나 지원을 직접 요청함 |
| `repair_attempt` | 사과, 책임 인정과 함께 관계 또는 대화의 회복을 시도함 |
| `withdrawal` | 대화나 상호작용에서 물러나려 함 |
| `disclosure` | 자신의 경험, 생각 또는 감정을 알림 |
| `request` | 일반적인 행동이나 정보를 요청함 |
| `neutral` | 뚜렷한 발화 기능이 없는 일반 진술 |
| `uncertain` | 주된 기능을 판단할 근거가 부족함 |

## Relation Signal

한 발화에 표현된 주된 관계 신호 하나를 선택한다.

| Label | 정의 |
|---|---|
| `trust_building` | 신뢰, 개방 또는 협력을 높이는 표현 |
| `boundary_setting` | 대화 범위, 시간 또는 접근에 대한 경계를 표현함 |
| `repair` | 손상된 관계나 대화를 회복하려는 표현 |
| `distancing` | 상대와의 관계적 거리를 늘리려는 표현 |
| `hostility` | 모욕, 위협 또는 적대가 상대를 향함 |
| `neutral` | 뚜렷한 관계 변화 신호가 없음 |
| `uncertain` | 관계 신호를 판단할 근거가 부족함 |

경계를 설명하면 `boundary_setting`, 상대 자체를 멀리하려는 표현이면 `distancing`을 우선한다.

## Safety Risk

| Label | 정의 |
|---|---|
| `none` | 제공된 문장에 명시적인 안전 위험 신호가 없음 |
| `caution` | 자해·타해·학대·위기 가능성을 추가로 확인해야 하는 표현 |
| `urgent` | 임박한 의도, 구체적인 계획 또는 현재 진행 중인 위험이 명시됨 |

안전 단계는 감정의 강도가 아니라 문장에 표현된 위험 근거로 판단한다. `urgent` 여부가 불명확하면 자동으로 낮추지 말고 `caution`으로 표시해 후속 확인 대상으로 둔다.

## Confidence와 근거

- `confidence`는 전체 분류 결과에 대한 0~1 사이의 확신도다.
- `evidence_spans`는 입력 문장에서 그대로 복사한 근거 문자열 배열이다.
- 입력에 없는 설명이나 해석을 `evidence_spans`에 생성하지 않는다.
